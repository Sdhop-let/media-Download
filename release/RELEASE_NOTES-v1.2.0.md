## Media Downloader v1.2.0

### 新功能
- **GitHub 更新检测**：设置 → 关于 → 检查更新；弹窗展示版本号、发布时间和更新说明，并可打开 APK 下载附件。
- **素材库全屏查看**：点击素材直接打开查看器；上下滑动只切换图片或只切换视频。
- **设置分组重排**：参照 Edqiu 目录卡样式归类为下载、账号、网络、素材、外观、关于六组。

### 查看器交互
- 浮层不自动隐藏；轻击切换浮层显隐。
- 视频双击暂停/继续；长按 5 秒打开详细操作页。

### 稳定性与兼容性
- 修复收件箱预览图大图加载失败与错误占位问题，并支持对旧条目补拉元数据。
- 修复 Android 16 16 KB 页对齐兼容性（Chaquopy 16.1.0）。
- 素材库时间视图改为连续 3 列网格与吸顶日期，并修正日期未知归组等问题。

### 安装要求
- Android 8.0（API 26）及以上。
- Debug 签名 APK；已安装本项目 Debug 版本可直接覆盖安装。
