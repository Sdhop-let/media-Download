# UI 设计方案

## 1. 设计原则

- **暗色优先**：素材浏览场景（图片/视频）在暗色下观感更好；支持一键浅色
- **信息密度适中**：素材库是主战场，卡片网格 + 紧凑工具栏；代理/设置页表单化
- **平台可辨识**：X = 白、Instagram = 粉紫渐变、Bluesky = 蓝色，用徽标 + 品牌色徽章区分
- **零构建**：原生 HTML/CSS/JS + Vue3（本地 vendored），启动即用，无 node_modules

- 卡片 hover 浮层四个操作：**回跳原帖**（浏览器打开 post_url）、**作者主页**（profile_url）、打开文件、删除
- 按作者模式：作者分组头（头像/昵称/handle/素材数/主页链接），组内按时间倒序；同帖素材自动去重（入库时已按 平台+帖子ID+序号 唯一约束）

### 3.4 设置页
下载目录（选择框）、并发数（1~8）、Cookies：Twitter / Instagram 两个 cookies.txt 路径 + 导出教程折叠说明、关于（版本/引擎版本）。

## 4. 设计 Tokens（暗色）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0f1115` | 页面背景 |
| `--bg-2` | `#161a22` | 卡片/侧栏 |
| `--bg-3` | `#1e2430` | 输入框/悬浮 |
| `--line` | `#262c3a` | 描边 |
| `--text` | `#e8ecf4` | 主文字 |
| `--text-2` | `#8b93a7` | 次要文字 |
| `--accent` | `#4f8cff` | 主色（按钮/选中） |
| `--ok` `--warn` `--err` | `#34d399` `#fbbf24` `#f87171` | 状态色 |
| 平台色 | X `#e7e9ea`·INS `#e1306c`·BSKY `#1185fe` | 徽章 |

圆角 10~14px；主字体 `system-ui / "Microsoft YaHei UI"`；动效仅 120~180ms 微过渡。

## 5. 交互细节

- 粘贴多行链接自动去空行、去重复；解析后按平台分组显示徽章，可逐条移除
- 任务进度：SSE 推送，进度条 + 实时速度 + 已完成/总数 + 去重跳过计数；失败可重试
- 素材库无限滚动分页（每页 60），切换排序/筛选重置分页
- 代理测速中按钮转 loading；表格行「使用中」徽章实时随自动切换更新
- 所有外部跳转（原帖/作者主页）用系统默认浏览器打开
